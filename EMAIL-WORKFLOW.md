# Email workflow

Future updates use Resend Broadcasts. The website does not create or send a newsletter when content changes.

1. Open Resend.
2. Create a Broadcast.
3. Select the `Sinda Website Updates` segment.
4. Choose the relevant Topic.
5. Write or paste the reviewed update.
6. Include the Resend unsubscribe placeholder and send a test email.
7. Review copy, links, sender details, Topic selection, and unsubscribe behavior.
8. Schedule or send.

Suggested categories: Book progress, Book launch, New technical article, Conference announcement, New personal project, and Major SKatalyst AI milestone.
