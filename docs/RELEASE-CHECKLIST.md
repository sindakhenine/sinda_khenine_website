# Website Release Checklist

- [ ] Resolve all public TBD fields and legal pages
- [ ] Confirm domain/site URL and canonical output
- [ ] Verify company/social/contact/purchase/media links
- [ ] Run lint, typecheck, test, build, route/link checks
- [ ] Keyboard, screen reader, contrast, reduced motion and 375/768/1440 checks
- [ ] Validate metadata, JSON-LD, sitemap and robots
- [ ] Confirm forms, retention, consent, double opt-in and processor contracts
- [ ] Obtain explicit approval before deployment
